Cross-platform Kotlin Multiplatform starter scaffold for Android and iOS.
The Compose UI and learning logic are shared; Android has a native launcher and iOS has an Xcode project that links the shared framework.
Not yet compiled or device-tested after cross-platform setup. iOS builds require macOS and Xcode.
Local AI runtime, production RAG index, persistent profile storage, full activities, and comprehensive UI/integration tests remain to be implemented.
